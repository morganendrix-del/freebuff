# @freebuff/auth

Status: **not started** — OAuth in Phase 3, magic links and phone OTP in Phases 4–5.

Scope: OAuth 2.0 (GitHub for repo import/eject, Google and GitHub for generated apps), magic-link
sign-in, Twilio-compatible phone OTP for free-tier abuse prevention, and session issuance/verification
for every surface.

Gate: a new user can authenticate on CLI, desktop and web with the same account, and phone
verification gates unverified free-tier accounts server-side.
